# Testing y Validación

## Objetivo
Validar el funcionamiento del prototipo con usuarios reales. Se busca que estos usuarios entiendan como conectar el prototipo al objeto eléctrico, para luego ver la información en la nube. El objetivo se considera éxito si la información es legible y fácil de entender.

## Metodología de Testing

### Grupo Objetivo
- **Perfil de usuarios:** Usuarios mayores a 18 años pertenecientes al 40% de hogares vulnerables según el Registro Social de Hogares, idealmente aquellos que no tienen el subsidio eléctrico. Tienen conocimientos básicos sobre dispositivos eléctricos residenciales
- **Cantidad mínima:** 5 usuarios
- **Ubicación:** En sus propios hogares.

### Protocolo de Testing
1. **Objetivo de la prueba**
- Evaluar la usabilidad, comprensión y utilidad del prototipo de monitoreo eléctrico desarrollado para estimar el consumo energético y el costo asociado de un dispositivo eléctrico en tiempo real. La evaluación busca determinar si los usuarios son capaces de instalar, utilizar e interpretar correctamente la información entregada por el sistema de manera autónoma.

2. **Fase de introducción y capacitación**
2.1 *Bienvenida*
- El responsable de la prueba dará la bienvenida al participante y explicará que se está evaluando el prototipo, no las capacidades del usuario.

2.2 *Presentación del proyecto*
-Se explicará brevemente que el sistema permite monitorear el consumo eléctrico de un dispositivo en tiempo real y estimar el costo asociado de acuerdo con una tarifa eléctrica previamente configurada. El objetivo es proporcionar información que ayude a los usuarios a comprender y gestionar mejor su consumo energético.

2.3 *Explicación del contexto de uso*
- Se indicará que el sistema debe utilizarse para monitorear un artefacto eléctrico específico conectado a una fuente de alimentación.

- Se explicará que el transformador de corriente mide la corriente consumida por el dispositivo. Las mediciones son procesadas por el sistema electrónico. La información se visualiza en una plataforma web. El sistema calcula una estimación del consumo y del costo monetario asociado.

2.4 *Instrucciones de instalación*

- El evaluador realizará una demostración breve del funcionamiento:

-Conectar el sensor de corriente al conector TRRS.
-Identificar el conductor por donde circula la corriente del dispositivo a medir.
-Posicionar correctamente el sensor alrededor del conductor.
-Conectar el dispositivo eléctrico al alargador preparado para la medición.
-Verificar que el módulo esté energizado.
-Acceder a la plataforma web.

2.5 *Acceso a la plataforma web*

- Se proporcionará URL de acceso y contraseña de acceso.

- Posteriormente, se realizará una explicación breve de los elementos presentes en la plataforma:

- Valor de corriente medida.
- Consumo estimado.
- Costo estimado.
- Estado de conexión del dispositivo.
- Historial o visualizaciones disponibles.

**3. Fase de prueba de uso**
3.1 *Actividad principal*

- El participante deberá operar el sistema de manera autónoma.
- Las tareas consisten en:
- Realizar la conexión del sensor.
- Preparar el dispositivo eléctrico para la medición.
- Acceder a la plataforma web.
- Verificar que los datos aparezcan correctamente.
- Interpretar la información mostrada.
- Identificar el consumo y costo estimado del dispositivo monitoreado.

3.2 *Rol del evaluador*

- Durante esta etapa el evaluador:
- No proporcionará ayuda excepto en situaciones de seguridad.
- No corregirá errores del participante.
- No responderá preguntas relacionadas con la operación del sistema.
- Únicamente registrará observaciones.

4. **Entrevista posterior a la prueba**

- Una vez finalizada la sesión, se realizará una entrevista breve utilizando preguntas abiertas.

- Preguntas:
- ¿Le resultó fácil instalar y utilizar el prototipo?
- ¿Comprendió cómo funciona el sistema?
- ¿La información mostrada en la plataforma web fue clara y comprensible?
- ¿Le pareció razonable la estimación del costo de consumo eléctrico?
- ¿Qué aspectos le resultaron más útiles?
- ¿Qué dificultades encontró durante el uso?
- ¿Qué mejoras incorporaría al sistema?
- ¿Utilizaría este sistema en su hogar para controlar sus gastos eléctricos?
